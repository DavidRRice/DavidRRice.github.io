Oh, the Places You'll Go!

Color the map based on where you've been or plan to go!

Upload your lists to create a travel map (instructions below) — everything runs locally in your browser, and nothing is saved or shared.

List order & colors

Drag-like with the arrow buttons to reorder; adjust colors if you like.


  


    

  
How to prepare your text files

  
    
    
  • Create a simple .txt file with one country per line.
    • 
    
  • You can use either the ISO-3 code (e.g. USA, FRA, JPN)
        or the country name (e.g. United States of America, France, Japan).
    • 
    
  • Don’t mix commas or extra formatting — just one entry per line.
    • 
    
  • Example:
      
    USA
CAN
MEX
BRA
      
    
    
    • 
    
  • You can upload multiple files (e.g. “Visited.txt”, “Planned.txt”). Each file will get its own color in the map and the name of the file will be used in the legend.
    • 
    
  • For U.S. states: make a separate .txt file with either full names (California, New York)
        or USPS codes (CA, NY, WI).
    •
